# Contributing

Contributions are welcome.

Please keep the project read-only: changes should not disable users, remove roles, alter group membership, or otherwise modify customer tenants automatically.

When proposing changes:

1. Do not include customer data, tenant IDs, usernames, tokens, or audit exports.
2. Explain the Microsoft 365 API or PowerShell behavior being changed.
3. Include a minimal reproduction for bugs where possible.
4. Keep compatibility with Windows PowerShell 5.1 unless a breaking change is explicitly documented.
