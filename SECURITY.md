# Security Policy

## Scope

This project is intended for read-only administrative auditing of Microsoft 365 privileged access.

## Reporting security issues

Please do not publish credentials, access tokens, tenant exports, customer audit reports, or other sensitive information in public issues or pull requests.

For a suspected security issue in the code, provide a minimal reproducible description without secrets or customer data.

## Data handling

Audit output can contain sensitive identity and access information. Keep generated workbooks in an approved private location and do not commit them to source control.
